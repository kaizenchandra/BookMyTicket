# ADR 108: Cab catalogue and configured tariff estimates

FR-10 adds a Cabs domain/application/PostgreSQL adapter inside the existing modular monolith. Cabs owns supplier references, vehicle categories, directional service coverage, tariff versions and immutable changes. Identity owns permissions and Reporting owns security audit. No other module's private tables are read or changed by Cabs. Migration 082 adds cabs.read/manage to assignable permissions without granting access.

Every HTTP operation requires current MFA and read access; writes also require manage. The application adapter rechecks grants in its transaction. Create replay is actor/operation/key scoped with a fingerprint, and kind/code uniqueness survives retries. Edits/incidents lock the record and check expectedVersion. Supplier/category references are share-locked and must be active. History, replay and audit writes commit atomically. History updates/deletes are rejected by a database trigger. Lists are newest-first, filtered before 25-row keyset pagination with actor/filter-bound cursors.

Service areas are explicit directional city/airport labels, compared case-insensitively after transport trimming. These are not polygons, address geocoding or route distance calculations. City endpoints must match; airport/outstation endpoints must differ. Availability configuration is an operating window and maximum trip distance, not vehicle stock. Fare preview validates the full trip fits the window and current category limits. A preview reads the current locked service version; it is not a durable accepted checkout quote.

Amounts use integer paise strings and bigint arithmetic. Fare = base + ceil(max(0,metres-includedMetres) * perKmPaise / 1000) + max(0,waitingMinutes-includedWaitingMinutes) * waitingMinutePaise + driverAllowance + airportFee. Fees are per trip, airport fees only for airport mode. Total duration includes waiting. Taxes, tolls and parking are excluded and visibly disclosed. Distance/duration come from the administrator; no routing API is implied.

Local incidents transition planned -> disrupted -> planned, or planned/disrupted -> withdrawn (terminal). They do not alter supplier trips, cancel reservations, issue refunds or send notifications. No real cab supplier contract/configuration has been supplied. Actual availability, booking/trip/cancellation status, actual charges and reconciliation remain null; bookable=false. Reservations, rescheduling, supplier escalations, callbacks/retries and reconciliation remain open requirements, not simulated successes.

Evidence: tests/cab-administration.test.ts, docs/evidence/cab-management-build.txt, docs/evidence/cab-management-full-suite.txt. Browser acceptance is unverified because the browser access host is unavailable.
