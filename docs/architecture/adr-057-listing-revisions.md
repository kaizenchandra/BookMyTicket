# ADR 057: Retained listing revision views

FE:CAT-06 and BE:CAT-07 require revision history as well as moderation reasons. Existing catalog.revisions rows contain pre-change snapshots from generic/category edits, submissions and reviews, including records predating durable decisions. New GET /api/v1/listings/:id/revisions and /api/v1/admin/listings/:id/revisions expose those retained rows through a Catalog application port. Member access uses the Providers public contract; moderators use Identity's authorization contract and existing route MFA policy. Reads use shared locks and atomic metadata-only auditing; failed audits withhold responses.

The API projects only snapshot title, description, city, kind and state, plus recorded reason, version, ID and timestamp. Metadata, poster URLs and unrecognized snapshot fields are excluded. Only moderator responses include actor ID, which may be null for legacy rows. A revision is a before-change snapshot, not an after-state or inferred review decision. Missing fields, actors and reasons remain unavailable rather than reconstructed. The current listing is not included in this historical feed.

Pagination orders by bigint revision ID descending, with 20 returned rows and a lookahead row. IDs/cursors remain decimal strings end to end to preserve precision above JavaScript's safe integer range. Validation rejects malformed or out-of-range IDs before SQL; the maximum is 9223372036854775807. Migration 053 adds the listing/ID index and a trigger rejecting UPDATE/DELETE of revision records. This protects retained evidence without creating or rewriting historical rows. Retention/remediation policy remains open.

Saved revision panels are integrated into the existing member/moderator history lookup pages. Loading is explicit; latest/older controls, empty/error/loading states and session clearing mirror decision history. Snapshot text and reasons are escaped, with clear before-change and missing-attribution labels. Category-specific metadata, structured diffs, restore actions and complete historical lifecycle reconstruction remain outside this increment.

Tests cover legacy snapshots with missing attribution, 23-row pagination, exact bigint boundaries, secret-field omission, role/membership revocation, audit failure, immutability and escaped rendering. Invalid fractional cursor testing found and corrected an unsafe BigInt conversion; final validation uses bounded decimal strings without throwing. Browser/navigation/accessibility and retention acceptance remain open.
