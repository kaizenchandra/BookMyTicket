# ADR 098: FR-02 dashboard analytics and historical captures

Scope: FE:FR-FE-007–012 and BE:FR-BE-007–012 from the supplied admin FRS, applied to BookMyTicket's movies/events/sports and INR. Travel products and travel-supplier integrations are absent; do not label them as zero-performing products. Completed-refund accounting and supplier-margin revenue are also absent; retain explicit unavailable disclosures.

The Reporting application orchestrates owner-module ports inside a repeatable-read local transaction. Catalog resolves current city/product/partner classification to listing references. Bookings resolves matching booking identities without a creation-date restriction for event-based payment/support attribution. Bookings, Payments, Inventory and Support only query their owned tables. Reporting owns immutable captured report payloads, query metadata and definition versions. No metric or report is inventory/booking sale authority, and no external network call runs in a report transaction.

Filters intersect. A booking matches when any saved occurrence references a matching current catalog listing; the whole order counts once. Mixed orders remain mixed/unmapped in vertical totals and are not apportioned without authoritative item allocation. Empty classification results remain an empty set, never an unfiltered query. Cash/support records may concern an older matching booking, because their own record date defines their reporting period. Inventory matches occurrence start and listing classification; booking-state filtering does not apply to inventory.

Bookings are grouped by creation cohort and current state. GBV includes orders with recorded confirmation, even if later cancelled; pending/refund-required orders without confirmation contribute zero. Active customers means distinct matching booking creators, not authenticated sessions or identity account status. Product totals include all order counts plus separate ever-confirmed counts/GBV. Captures, latest failed/refunded attempts, current payment order exceptions and recovery cases are separate measures. Support counts are unresolved/escalated/high-priority cases created within the selected period. No all-time backlog claim is made.

Periods use half-open Asia/Kolkata boundaries; presets derive from database transaction time. Series use daily buckets for <=62 days and monthly buckets otherwise, with explicit zero filling. Integer aggregate monetary values are decimal paise strings; ratios/chart proportions use BigInt before bounded conversion for presentation.

Migration 073 stores historical reports on refresh. Updates are denied by a trigger; no update/delete API exists. Reads require current finance/MFA; support aggregates require current support permission, including historical reads. Snapshots preserve the captured metric state and definitions and are not reconstructed historical day-end projections. History lists the latest 20 captures; older captures remain retrievable by ID. Retention/archival and production volume/load policies require separate operational work.

KPI drilldowns use pinned period dates and exactly the selected filters, with descending timestamp/UUID pagination. Cursors bind actor, filters, kind and period. Finance is always required; booking/customer/support drilldowns additionally require their own platform grants. Records exclude customer contacts, provider IDs, arbitrary snapshots, ticket credentials and support subjects. Historic reports do not offer misleading historical-row drilldowns; booking details are clearly labeled current.

Tests verify multi-filter intersections, no-match sets, cohort/event-date separation, zero-filled series, totals reconciliation, pagination/cursor scope, rejected unknown currencies/filters, sensitive-field exclusion, snapshot immutability and current authorization. Build and SQL/import ownership checks pass. Browser access host is unavailable, so visual/accessibility acceptance remains open. Source reads are authoritative tables with scoped identity lists; production-scale precomputed projections and load testing remain open.
